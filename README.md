# НЕ ВЕДИСЬ!

Самостоятельный браузерный образовательный симулятор для «СтудПедОлимп». Проект целиком находится в этой папке; он не импортирует файлы или зависимости «Дожить до диплома» и использует собственное сохранение `ne-vedis-v1`.

## Запуск

Требуется Node.js 22+ и pnpm 11.

```bash
cd ne-vedis
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, напечатанный Vite. Не открывайте исходный index.html двойным нажатием: браузеру нужен локальный HTTP-сервер. Никаких ключей, аккаунтов или серверной базы не требуется.

## Проверки и сборка

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
pnpm preview
```

Сборка находится в dist. Vite использует относительную базу, поэтому подходит для GitHub Pages. Workflow .github/workflows/pages.yml выполняет проверки и публикует dist после настройки Pages → GitHub Actions в отдельном репозитории этого проекта. Репозиторий проекта: https://github.com/zizy22545-jpg/ne-vedis. Университетская ЭИОС не подключена.

## Что есть

Изометрическая комната и настраиваемый студент; семь сценариев и финал; три исхода; режим «Юрист»; разбор и справочник с источниками; отдельная оценка пяти компетенций; деньги и стресс; сохранения, достижения, настройки звука и анимаций; преподаватель и демо; JSON; PDF через системную печать.

Команда и авторы добавляют свои сведения перед конкурсной подачей. Все названия сервисов, профили, данные и операции учебные. Демонстрационная страница не собирает реквизиты, пароли и коды.

## GitHub Pages и проверка опубликованной версии

GitHub Pages настроен на GitHub Actions. Публикуется только содержимое `dist`,
без локальных сохранений и исходных персональных данных игроков. Проверенный публичный
адрес: https://zizy22545-jpg.github.io/ne-vedis/.
Приложение использует `base: './'` и переключение экранов без серверных маршрутов.

Тот же браузерный набор можно запустить против готового сайта:

```bash
PLAYWRIGHT_BASE_URL=https://zizy22545-jpg.github.io/ne-vedis/ pnpm test:e2e
```

Тесты используют отдельные браузерные контексты и вымышленные данные. Итоги
этого запуска сохраняются в `test-results/published/e2e.json`.
При новом домене прогресс старого адреса не переносится автоматически:
LocalStorage привязан к адресу браузера.

Повреждённые кампании при загрузке отбрасываются; остальные валидные кампании
сохраняются. При запрете LocalStorage игра работает в памяти до закрытия страницы.
