# Архитектура

Отдельный проект ne-vedis. Ни исходники, ни зависимости, ни сохранения прежнего симулятора не используются. React 19 + TypeScript + Vite, Zustand persist, CSS Modules. Свои package.json, lockfile, pnpm-workspace.yaml, конфигурации и тесты. Сервер приложения не требуется; Vite используется только для разработки/сборки.

## Модули

- src/data.ts: восемь сценариев, исследовательские действия, реплики, критические шаги, правовые вопросы, источники и нормы.
- src/engine.ts: чистые функции начала, исследования, исхода, правового ответа, оценки и ресурсов.
- src/store.ts: переходы экранов и три независимые кампании story/demo/teacher, сохранение в localStorage под ne-vedis-v1.
- src/App.tsx: экраны и взаимодействия в телефоне, браузере, переписке, отчёте и панели преподавателя.
- src/Room.tsx: векторная изометрическая комната, зоны взаимодействия, персонализируемый студент.
- src/icons.tsx: единая SVG-система пиктограмм, без эмодзи.
- src/App.module.css и base.css: адаптивная дизайн-система, фокус, reduced motion, печать.
- src/integration.ts: схема JSON-отчёта и интерфейс LearningAdapter. Реального провайдера авторизации нет.

## Машина эпизода

active → critical (при согласии на опасную инструкцию) → law → debrief.
active → law возможен при ранней остановке. Из critical доступны отмена/защита и подтверждение. Из debrief доступны следующая сцена и повтор. На active доступны уникальные исследования; история диалога сохраняется.

## Состояние

Episode хранит id, seen, history, evidence, risk, phase, outcome и legalChoice. Result фиксируется после правового ответа. Перезапуск эпизода создаёт новую попытку, но не удаляет прежний результат до её завершения; завершение заменяет Result того же id. Ресурсы производны от результатов, что предотвращает накопительный фарм.

Хранилище версионировано. Недоступный localStorage не ломает игру, выводится предупреждение о временном хранении. Повреждённая JSON-запись и несовместимая структура верхнего уровня игнорируются; это не криптографически защищённая аттестация, пользователь может менять данные браузера.

## Почему без Phaser

Основные взаимодействия — интерфейсы, диалог, исследование информации и решения. React обеспечивает доступность и адаптивность; SVG достаточен для комнаты, графиков, предметов и безопасной анимации. Физика и пространственная аркада не нужны.

## Публикация

Vite base './' позволяет раздачу из подкаталога GitHub Pages. Нет серверных маршрутов и внешних шрифтов. Интернет нужен только для перехода к внешним правовым источникам. Сборка dist содержит HTML, CSS и JS. GitHub Actions приведён в .github/workflows/pages.yml; репозиторий и Pages пользователь настраивает в своём GitHub.

## Безопасность

Вымышленные домены .example показаны текстом, не запрашиваются приложением. Сбор банковских реквизитов и паролей отсутствует. Демо-авторизация использует фиксированные STUDENT-DEMO и DEMO. Нет fetch, платёжных SDK, отправки сообщений, аналитики и реальных аккаунтов. Проверки банка/реестра — явно учебные ответы, без обращения к настоящим базам.
