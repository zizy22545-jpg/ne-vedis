# Демо для жюри • 5–7 минут

Демо включается кнопкой в главном меню. Создаётся отдельное прохождение demo, личная история не затрагивается. Никаких заранее нарисованных 100 баллов нет: оцениваются только совершённые действия. Названия схем до эпизода не раскрываются. Субтитры всегда видимы; звук можно включить в настройках.
