# «НЕ ВЕДИСЬ!»

Конкурс «СтудПедОлимп», номинация «Иммерсивный университет». Аудитория: студенты 17–25 лет. Авторские сведения и вуз команды должны быть добавлены участниками перед подачей; не приписываются автоматически.

## Проблема и цель

Знание лозунга «не сообщайте код» не всегда помогает при авторитетном, эмоциональном и срочном обращении. Студентам нужны безопасная практика самостоятельной проверки и понимание пределов юридического вывода. Цель проекта — формировать пять компетенций через решения в смоделированных цифровых ситуациях.

## Продукт

Автономное браузерное приложение: семь дней студенческой жизни и комбинированный финал. Стартовая комната, персонаж, телефон, ноутбук и документы объединяют историю. Игрок задаёт вопросы, изучает сведения, связывается с независимым каналом, принимает либо отменяет рискованное действие. После каждого эпизода открываются режим «Юрист», разбор из пяти блоков и прозрачная оценка.

Сценарии: телефонный звонок, фишинговое сообщение, покупка ноутбука, аренда, вакансия с чужими платежами, инвестиционный проект, подмена личности в видео. В обычном прохождении заголовки дней нейтральны и не называют схему заранее. Подробности раскрываются после эпизода и в преподавательской панели.

## Практическая значимость

Возможны самостоятельное прохождение, семинар с обсуждением, демонстрация для жюри. Работа без регистрации и внешнего API позволяет разместить статическую сборку на GitHub Pages. Прогресс хранится локально; отчёт экспортируется в JSON и PDF через браузерную печать.

## Ограничения результата

Это образовательный симулятор, а не диагностика личности и не юридическая консультация. Эффективность методики не подтверждена педагогическим экспериментом. Правовая проверка законодательства на октябрь 2026 года проведена; подтверждение пользователя получено 19.10.2026. Содержимое и ограничения подробно описаны в implementation-status.md.
