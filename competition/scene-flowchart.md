# Схема переходов

```mermaid
flowchart TD
  Menu[Главное меню] --> Create[Создание студента]
  Menu --> Demo[Отдельная кампания демо]
  Menu --> Teacher[Панель преподавателя]
  Menu --> Book[Правовой справочник]
  Create --> Room[Комната студента]
  Room --> Event[Событие без названия схемы]
  Event --> Inspect[Диалог и исследование среды]
  Inspect --> Verify[Независимая проверка]
  Inspect --> Stop[Остановка контакта]
  Verify --> Stop
  Inspect --> Critical[Критический шаг]
  Critical --> Recover[Отмена и защита доступа]
  Critical --> Loss[Учебное негативное последствие]
  Stop --> Lawyer[Режим Юрист]
  Recover --> Lawyer
  Loss --> Lawyer
  Lawyer --> Debrief[Пять блоков правового разбора]
  Debrief --> Replay[Повтор эпизода]
  Replay --> Event
  Debrief --> Next{Режим и прогресс}
  Next -->|История продолжается| Room
  Next -->|Семь дней пройдены| Final[Комбинированный финал]
  Final --> Inspect
  Next -->|Два эпизода демо| Report[Образовательный отчёт]
  Next -->|Преподаватель| Teacher
  Teacher --> Event
  Teacher --> Report
  Room --> Report
  Report --> PDF[Печать и сохранение PDF]
  Report --> JSON[Экспорт JSON]
  Demo --> Room
```

Идентификаторы дней: 1 звонок, 2 сообщение, 3 магазин, 4 аренда, 5 работа, 6 инвестиции, 7 видеосообщение, 8 комбинированный финал. При обычной игре с комнаты доступен первый незавершённый день; выбор сценария позволяет отдельно переиграть день. Финал закрыт до семи завершённых глав; преподавателю доступен сразу.
